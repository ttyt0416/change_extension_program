이 프로젝트는 포토샵, 확장자 변환 응용 프로그램 프로젝트입니다.

## 지원하는 파일 변환

| 분야 | 입력 파일 | 변환할 수 있는 형식 |
| --- | --- | --- |
| 이미지 | PNG, JPG/JPEG, GIF, BMP, TIFF/TIF, WEBP, ICO, TGA, PNM, QOI | PNG, JPG/JPEG, GIF, BMP, TIFF/TIF, WEBP, ICO, TGA, PNM, QOI |
| 소리 | WAV, MP3, FLAC, OGG, AAC, M4A, AIFF/AIF, CAF | WAV, FLAC, MP3 |
| 동영상 | MP4, M4V, MOV | MP4, M4V, MOV |

이미지는 정지 이미지만 변환합니다. 움직이는 GIF와 WEBP는 지원하지 않습니다. 소리 파일은 내부 코덱이 지원되는 경우 변환할 수 있으며, 입력 파일을 이용해 확인한 형식은 WAV, MP3, FLAC입니다.

### 문서

| 입력 파일 | 변환할 수 있는 형식 |
| --- | --- |
| TXT | MD, HTML |
| MD | TXT, HTML |
| HTML, HTM | TXT |
| CSV | TSV |
| TSV | CSV |
| PDF | TXT |
| DOCX | TXT, PDF, HWP, HWPX |
| HWP (5.0) | DOCX, HWPX |
| HWPX | DOCX, HWP |
| ODT | TXT |

PDF에서 TXT로 변환할 때는 추출 가능한 텍스트만 처리합니다. DOCX와 ODT에서 TXT로 변환할 때도 문서의 텍스트를 추출합니다.

DOCX ↔ HWP, DOCX ↔ HWPX, HWP ↔ HWPX를 한글 프로그램 설치 없이 자체 변환합니다. HWP는 5.0 형식을 지원합니다. 문단, 한글·유니코드 텍스트, 줄바꿈·탭, 기본 글자 서식(글꼴·크기·굵게·기울임·밑줄·취소선·색상), 문단 정렬·여백, 일반 표와 셀 병합을 처리합니다.

원본의 페이지 배치와 표 디자인은 달라질 수 있습니다. 그림·수식·글상자·자동 번호·각주·머리말/꼬리말·변경 추적·표 캡션·중첩 표 등 복합 문서는 아직 지원하지 않으며, 암호·배포 제한·DRM이 적용된 문서도 지원하지 않습니다.

HWPX는 일반적인 2011 OWPML 네임스페이스를 사용한 문서를 처리합니다. 용지 설정이 다른 여러 구역·다단·세로쓰기·바탕쪽·제본 여백, 표와 본문 텍스트가 섞인 문단, 표 문단에 직접 적용된 쪽 나눔은 아직 지원하지 않습니다. 지원할 수 있는 입력에서만 DOCX·HWP·HWPX 출력 형식이 표시됩니다.

왕복 변환 테스트와 외부 HWP·HWPX 샘플, 별도 판독기로 검증했습니다. 실제 한글 앱에서의 표시 검증은 아직 하지 않았습니다.

본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

동영상은 H.264 영상과 AAC 소리가 들어 있는 MP4 계열 파일의 형식 식별자를 바꾸며, 영상·소리·재생 시간 정보는 그대로 보존합니다. MOV 파일도 MP4 호환 구조일 때 처리할 수 있습니다. 다른 영상·소리 코덱, 자막 트랙, 분할 저장된 MP4와 AVI·MKV·WEBM 등 다른 컨테이너는 아직 지원하지 않습니다.
